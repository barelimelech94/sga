# Third-party notices

The body-group icons are derived from muscle outline polygons published in two MIT-licensed projects.

- `tools/body_polygons.json` holds polygon coordinates taken from `src/assets/index.ts` of
  [react-body-highlighter](https://github.com/giavinh79/react-body-highlighter) (commit `d03fcd8740033721a51f5a2682de02ec31df92ba`).
  That project's README says the polygons came from
  [react-native-body-highlighter](https://github.com/HichamELBSI/react-native-body-highlighter).
- `tools/gen_body_icons.py` reads that file and generates `app/src/main/res/drawable/ic_body_*.xml`
  (`ic_body_chest`, `ic_body_back`, `ic_body_shoulders`, `ic_body_rear_delts`, `ic_body_biceps`,
  `ic_body_triceps`, `ic_body_legs`, `ic_body_core`, `ic_body_other`). Those drawables are derived from the same polygons.
